IRON//PROTOCOL — PWA
======================

Este pacote é um site PWA.

Depois de hospedado em HTTPS:
1. Abra o endereço no Safari do iPhone.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início".
4. O IRON//PROTOCOL aparecerá como um aplicativo.

Arquivos:
- index.html
- manifest.json
- service-worker.js
- icon.svg

Observação: o navegador precisa de HTTPS para Service Worker/PWA.
